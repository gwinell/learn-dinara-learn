# Пинг-понг в терминале на языке C: разбор программы с нуля

Этот документ объясняет, как работает программа `pong.c` — пошаговая игра
«пинг-понг», которая рисуется прямо в терминале. Текст рассчитан на человека,
который из C знает только `printf` и `scanf`. Поэтому сначала мы разберём
весь необходимый «теоретический минимум» языка, а потом пройдём по коду
функция за функцией.

---

## 1. Что делает программа

После запуска в терминале рисуется поле 80 символов в ширину и 25 символов
в высоту:

```
Player: 0                                                              Player: 0
--------------------------------------------------------------------------------
|                                       :                                      |
|                                       :                                      |
...
|#                                      *                                     #|
|#                                      :                                     #|
|#                                      :                                     #|
...
--------------------------------------------------------------------------------
A/Z: left up/down | K/M: right up/down | Enter: skip turn
```

- `Player: 0` слева и справа — счёт левого и правого игрока.
- `#` — ракетки (по 3 клетки высотой): левая у края слева, правая у края справа.
- `*` — мяч, в начале каждого розыгрыша появляется в центре.
- `:` — линия по середине поля.
- Нижняя строка — подсказка по управлению. Когда кто-то набирает 21 очко,
  на её месте появляется `Player 1 (left) wins!` или `Player 2 (right) wins!`.

Игра **пошаговая**: вы нажимаете клавишу и Enter — программа двигает
соответствующую ракетку на одну клетку, сдвигает мяч на одну клетку и
перерисовывает поле. Пустой ввод (просто Enter) — пропуск хода: ракетки
стоят, мяч летит.

Управление:

| Клавиша | Действие                  |
|---------|---------------------------|
| `A`     | левая ракетка вверх       |
| `Z`     | левая ракетка вниз        |
| `K`     | правая ракетка вверх      |
| `M`     | правая ракетка вниз       |
| `Enter` | пропуск хода              |

Осознанные ограничения программы:

- используется только заголовок `stdio.h` (ничего больше подключать нельзя);
- нет массивов и структур — только обычные переменные;
- нет `#define` и именованных констант;
- в начале файла идут **объявления** функций, потом `main`, а **определения**
  функций — после `main`;
- `main` не длиннее 40 строк.

## 2. Как устроен файл целиком

Файл `pong.c` состоит из четырёх частей, идущих сверху вниз:

```c
#include <stdio.h>          // 1. подключение библиотеки ввода-вывода

void clear_screen(void);    // 2. ОБЪЯВЛЕНИЯ (прототипы) всех функций
...
unsigned int *seed);        //    (только заголовки, без тел)

int main(void) {            // 3. функция main — точка входа
    ...
}

void clear_screen(void) {   // 4. ОПРЕДЕЛЕНИЯ функций (заголовок + тело)
    ...
}
```

Зачем нужны объявления (прототипы)? Компилятор C читает файл строго сверху
вниз. Когда он внутри `main` встречает вызов `clear_screen()`, он уже должен
знать, что такая функция существует, какие у неё параметры и что она
возвращает. Прототип — это «анонс»: имя, типы параметров, тип результата.
Само тело функции компилятор найдёт ниже. Именно поэтому программа начинается
со списка прототипов, а `main` может вызывать функции, которые написаны
после неё.

## 3. Минимум языка C, который нужен для понимания кода

### 3.1. `#include <stdio.h>`

`stdio.h` — стандартная библиотека ввода-вывода (**st**an**d**ard **i**nput/**o**utput).
Строка `#include <stdio.h>` вставляет в программу описания функций `printf`,
`scanf`, `getchar` и других. Без этой строки компилятор их «не знает».

### 3.2. Переменные и типы

Переменная — именованная ячейка памяти. Перед использованием её нужно
объявить: указать тип и имя.

```c
int ball_x;            // объявление: ball_x — целое число
int ball_y = 12;       // объявление + начальное значение
ball_x = 40;           // присваивание нового значения
```

В программе используются два типа:

- `int` — целое число (может быть отрицательным): координаты, счёт,
  направление движения.
- `unsigned int` — целое число **без знака**, то есть только неотрицательное
  (0, 1, 2, ...). Используется для «зерна» генератора случайных чисел, потому
  что для него чётко определено поведение при переполнении (об этом ниже).

### 3.3. Операторы

Арифметика:

```c
a + b    // сложение
a - b    // вычитание
a * b    // умножение
a / b    // деление (для int — целочисленное: 7 / 2 == 3)
a % b    // остаток от деления: 7 % 2 == 1, 8 % 3 == 2
```

Сокращённые формы:

```c
a += 1;  // то же, что a = a + 1;
a++;     // то же, что a = a + 1;
a -= 2;  // то же, что a = a - 2;
a /= 10; // то же, что a = a / 10;
```

Сравнения (результат — «истина» или «ложь»):

```c
a == b   // равно (важно: ДВА знака равенства; одно = — это присваивание!)
a != b   // не равно
a < b    // меньше
a <= b   // меньше или равно
a > b    // больше
a >= b   // больше или равно
```

Логические связки:

```c
условие1 && условие2   // И: истина, только если оба истинны
условие1 || условие2   // ИЛИ: истина, если хотя бы одно истинно
!условие               // НЕ: переворачивает значение
```

### 3.4. Ветвление: `if / else if / else`

```c
if (x == 1) {
    // выполнится, если x равен 1
} else if (x == 2) {
    // выполнится, если первое условие ложно, а x равен 2
} else {
    // выполнится, если все условия выше ложны
}
```

Проверки идут сверху вниз; выполняется только **первая** подошедшая ветка,
остальные пропускаются.

### 3.5. Циклы: `while` и `for`

`while` — «повторять, пока условие истинно»:

```c
while (winner == 0) {
    // тело цикла повторяется, пока winner равен 0
}
```

`for` — удобная форма цикла со счётчиком:

```c
for (y = 0; y < 25; y++) {
    // тело выполнится для y = 0, 1, 2, ..., 24 — всего 25 раз
}
```

Он читается так: «начни с `y = 0`; пока `y < 25`, выполняй тело; после
каждого прохода увеличивай `y` на 1».

Циклы можно вкладывать друг в друга. В `draw` вложенные циклы по `y` и по `x`
перебирают каждую клетку поля: сначала строка `y = 0` целиком (все `x` от 0
до 79), потом строка `y = 1` и так далее.

### 3.6. Функции

Функция — именованный кусок кода, который можно вызывать много раз.

```c
int move_paddle(int paddle_y, int direction) {   // заголовок
    paddle_y += direction;                       // тело
    return paddle_y;                             // вернуть результат
}
```

Разбор заголовка:

- `int` перед именем — **тип результата**: функция вернёт целое число.
- `move_paddle` — имя функции.
- В скобках — **параметры**: данные, которые функция получает при вызове.
  Здесь их два: `paddle_y` (текущая позиция ракетки) и `direction`
  (направление: `-1` вверх, `1` вниз).

Вызов:

```c
left_paddle = move_paddle(left_paddle, -1);
```

**Важно:** в C параметры передаются **по значению**, то есть функция получает
*копии*. Если внутри функции изменить параметр, переменная снаружи не
изменится. Поэтому `move_paddle` не меняет `left_paddle` «на месте», а
**возвращает** новое значение через `return`, и мы сами присваиваем его
обратно.

Если функция ничего не возвращает, тип результата — `void` («пусто»), и
`return` со значением не нужен:

```c
void clear_screen(void) {
    printf("...");
}
```

Слово `void` в скобках означает «параметров нет».

### 3.7. Указатели: `&` и `*`

Это самое сложное место, но без него программу не понять.

У каждой переменной есть **адрес** — номер ячейки в памяти. Оператор `&`
(амперсанд) даёт адрес переменной:

```c
int left_paddle = 13;
&left_paddle   // адрес переменной left_paddle
```

**Указатель** — это переменная, которая хранит адрес. Тип «указатель на int»
записывается как `int *`:

```c
int *p = &left_paddle;   // p хранит адрес left_paddle
```

Оператор `*` (звёздочка) делает обратное: по адресу добирается до значения.
Это называется **разыменование**:

```c
*p       // значение переменной, на которую указывает p, то есть 13
*p = 5;  // записать 5 ПО АДРЕСУ p — теперь left_paddle стала равна 5!
```

Зачем это нужно? Вспомним: параметры передаются копиями. Но что, если функция
должна изменить переменную вызывающего кода — например, `update_ball` должна
обновить и координаты мяча, и направление, и счёт (шесть переменных сразу)?
Через `return` можно вернуть только одно значение.

Решение: передать в функцию **не значения, а адреса** переменных. Тогда
функция через `*` сможет читать и менять настоящие переменные:

```c
void update_seed(unsigned int *seed) {   // принимает АДРЕС переменной
    *seed = *seed * 1103515245u + 12345u; // меняет переменную по этому адресу
}

// вызов:
update_seed(&seed);   // передаём адрес seed — функция изменит саму seed
```

Схема чтения кода с указателями:

- в заголовке `int *seed` — «параметр `seed` — указатель на int»;
- в теле `*seed` — «значение переменной, чей адрес лежит в `seed`»;
- при вызове `&seed` — «передаём адрес нашей переменной `seed`».

### 3.8. Ввод: `getchar`, буфер и `'\n'`

`scanf("%d", &x)` вам знаком: он читает данные из **буфера ввода**. Когда вы
печатаете символы и жмёте Enter, всё набранное (включая сам Enter)
попадает в этот буфер, а функции ввода забирают символы оттуда по одному.

`getchar()` — простейшая функция ввода: она берёт из буфера **ровно один
символ** и возвращает его код (число типа `int`). Если буфер пуст, программа
останавливается и ждёт, пока пользователь что-нибудь введёт и нажмёт Enter.

Ключевые факты:

- Каждый символ — это число (его код). Символ `'a'` — это код 97, `'A'` —
  65 и т.д. Запись `'a'` в апострофах означает «код символа a». Поэтому
  результат `getchar()` можно сравнивать: `if (c == 'a')`.
- Когда вы нажимаете Enter, в буфер попадает специальный символ **новой
  строки** `'\n'` (код 10). Запись `'\n'` — один символ, хотя пишется двумя
  знаками.
- Если ввода больше нет (например, файл с вводом закончился), `getchar()`
  возвращает специальное значение `EOF` (**e**nd **o**f **f**ile), описанное
  в `stdio.h`.

Пример. Пользователь нажал `a`, потом Enter. В буфере оказалось два символа:
`'a'` и `'\n'`. Первый вызов `getchar()` вернёт `'a'`, но `'\n'` останется
в буфере! Если его не убрать, следующий `getchar()` прочитает этот `'\n'`
вместо новой команды. Поэтому в `read_command` есть цикл, который
«дочитывает» буфер до символа `'\n'` — мы разберём его ниже.

### 3.9. ANSI-последовательности: управление терминалом

Терминал умеет не только печатать текст, но и выполнять команды: очистить
экран, передвинуть курсор, сменить цвет. Команды задаются **управляющими
последовательностями** — строками, начинающимися с невидимого символа ESC
(код 27), который в C записывается как `'\033'` (33 — это восьмеричная
запись числа 27).

Используемые в программе последовательности:

| Последовательность | Действие |
|--------------------|----------|
| `\033[2J`          | очистить весь экран |
| `\033[H`           | переместить курсор в левый верхний угол (строка 1, колонка 1) |
| `\033[?25l`        | спрятать курсор (чтобы не мерцал при перерисовке) |
| `\033[?25h`        | показать курсор обратно |
| `\033[<строка>;<колонка>H` | переместить курсор в заданную позицию |
| `\033[1;31m`       | дальнейший текст — ярко-красный |
| `\033[1;32m`       | ярко-зелёный |
| `\033[34m`         | синий |
| `\033[37m`         | белый |
| `\033[1;36m`       | ярко-голубой |
| `\033[33m`         | жёлтый |
| `\033[1;35m`       | ярко-пурпурный |
| `\033[0m`          | сбросить все цвета и атрибуты |

Терминал не печатает эти последовательности как текст — он их выполняет.
Поэтому «рисование» в программе устроено так: печатаем команду «перейди в
позицию (y, x)», затем печатаем команду «включи красный», затем сам символ
`*`, затем «сбрось цвет». Например:

```c
printf("\033[%d;%dH", 5, 10);   // курсор в строку 5, колонку 10
printf("\033[1;31m*\033[0m");   // ярко-красная звёздочка, цвет сброшен
```

Нумерация строк и колонок в терминале начинается с 1, а не с 0.

## 4. Модель игры: как поле превращается в числа

Прежде чем читать код, поймите главную идею: вся игра описана **несколькими
числами**, а рисование — это просто печать символов по этим числам.

Координаты поля:

```
x:  0          1   ...   40   ...   78   79
y=0  --------------------------------------   <- верхняя граница
y=1  |                 :                    |
...  |                 :                    |
y=12 |#                :        *          #|  <- ракетки и мяч
...  |                 :                    |
y=23 |                 :                    |
y=24 --------------------------------------   <- нижняя граница
```

- Поле: `x` от 0 до 79 (80 колонок), `y` от 0 до 24 (25 строк).
- Строки 0 и 24, колонки 0 и 79 — границы. Внутри поля: `y` от 1 до 23.
- Левая ракетка стоит в колонке `x = 1`, правая — в колонке `x = 78`.
- Позиция ракетки — это координата `y` её **центра**. Ракетка занимает
  три клетки: от `center - 1` до `center + 1`.
- Центральная линия — колонка `x = 40`.

Состояние игры (всё это обычные переменные в `main`):

| Переменная    | Смысл                                        |
|---------------|----------------------------------------------|
| `left_paddle` | y центра левой ракетки (старт: 13)           |
| `right_paddle`| y центра правой ракетки (старт: 13)          |
| `ball_x`, `ball_y` | координаты мяча                         |
| `dir_x`, `dir_y`   | направление мяча: куда он сместится за ход |
| `score_left`, `score_right` | счёт                           |
| `winner`      | 0 — игра идёт, 1 — победил левый, 2 — правый |
| `win_score`   | сколько очков нужно для победы (21)          |
| `command`     | код последней нажатой клавиши                |
| `seed`        | «зерно» генератора случайных чисел           |

Направление мяча — тоже числа. За один ход мяч сдвигается так:

```c
next_x = ball_x + dir_x;
next_y = ball_y + dir_y;
```

- `dir_x == 1` — мяч летит вправо, `dir_x == -1` — влево.
- `dir_y == -1` — вверх, `dir_y == 0` — прямо, `dir_y == 1` — вниз.

Пошаговый цикл игры (одна итерация `while` = один ход):

1. нарисовать поле по текущим числам;
2. прочитать команду с клавиатуры;
3. сдвинуть соответствующую ракетку;
4. сдвинуть мяч (с отскоками и проверкой гола);
5. проверить, не набрал ли кто-то 21 очко.

## 5. Разбор функций

### 5.1. `main` — дирижёр программы

```c
int main(void) {
    int left_paddle = 13;
    int right_paddle = 13;
    int ball_x;
    int ball_y;
    int dir_x;
    int dir_y;
    int score_left = 0;
    int score_right = 0;
    int winner = 0;
    int win_score = 21;
    int command;
    unsigned int seed = 123456789;

    serve_ball(&ball_x, &ball_y, &dir_x, &dir_y, &seed);

    while (winner == 0) {
        draw(left_paddle, right_paddle, ball_x, ball_y,
             score_left, score_right, winner);
        command = read_command();
        apply_command(command, &left_paddle, &right_paddle);
        update_ball(&ball_x, &ball_y, &dir_x, &dir_y,
                    left_paddle, right_paddle,
                    &score_left, &score_right, &seed);
        if (score_left >= win_score) {
            winner = 1;
        } else if (score_right >= win_score) {
            winner = 2;
        }
    }

    draw(left_paddle, right_paddle, ball_x, ball_y,
         score_left, score_right, winner);
    printf("\033[?25h\n");
    return 0;
}
```

По шагам:

1. **Объявляются все переменные состояния.** Ракетки начинают с середины
   (`y = 13`), счёт 0:0, `winner = 0` (игра идёт). Координаты и направление
   мяча пока не заданы — их заполнит `serve_ball`. `seed` — стартовое зерно
   генератора случайных чисел, любое большое число.
2. **`serve_ball(&ball_x, ...)`** — первая подача мяча. Передаются адреса
   (`&`), потому что функция должна записать значения в четыре переменные
   `main` и обновить `seed`.
3. **`while (winner == 0)`** — главный цикл: повторяем ходы, пока нет
   победителя. Одна итерация:
   - `draw(...)` — нарисовать кадр. Сюда достаточно передать значения
     (копии), потому что рисовалка ничего не меняет.
   - `command = read_command();` — прочитать клавишу, получить её код
     (0 — пропуск, 1–4 — движение ракеток).
   - `apply_command(command, &left_paddle, &right_paddle);` — сдвинуть
     ракетку. Адреса нужны, чтобы функция изменила переменные `main`.
   - `update_ball(...)` — сдвинуть мяч, обработать отскоки и голы. Меняет
     шесть переменных — все они переданы по адресу.
   - Проверка победы: если счёт достиг `win_score`, записываем номер
     победителя в `winner`, и цикл на следующей проверке завершится.
4. **После цикла** — финальный `draw(...)`: он покажет то же поле, но вместо
   подсказки напечатает, кто победил (потому что `winner` уже не 0).
5. **`printf("\033[?25h\n")`** — вернуть видимый курсор (мы прятали его на
   время игры) и перевести строку, чтобы приглашение терминала не оказалось
   наполовину в поле.
6. **`return 0;`** — сообщить системе, что программа завершилась успешно.

### 5.2. `clear_screen` — очистка экрана

```c
void clear_screen(void) {
    printf("\033[2J\033[H\033[?25l");
}
```

Печатает три ANSI-команды подряд: очистить экран, курсор в левый верхний
угол, спрятать курсор. Вызывается в начале каждого кадра: старый кадр
стирается, новый рисуется с чистого листа.

### 5.3. `move_cursor` — курсор в нужную клетку

```c
void move_cursor(int row, int col) {
    printf("\033[%d;%dH", row, col);
}
```

Печатает последовательность `\033[<row>;<col>H`. Спецификаторы `%d` в
`printf` подставляют числа в строку: при `row = 5`, `col = 10` напечатается
`\033[5;10H`, и курсор встанет в строку 5, колонку 10. Всё «рисование»
дальше идёт через эту функцию: сначала встаём в клетку, потом печатаем
символ.

### 5.4. `count_digits` — сколько цифр в числе

```c
int count_digits(int n) {
    int count = 1;
    while (n >= 10) {
        n /= 10;
        count++;
    }
    return count;
}
```

Зачем: правую часть счёта (`Player: 21`) нужно прижать к правому краю
строки, а её позиция зависит от того, одна цифра в счёте или две.

Как работает: любое число имеет минимум одну цифру (`count = 1`). Пока число
не меньше 10, отсекаем последнюю цифру целочисленным делением на 10 и
увеличиваем счётчик. Пример для `n = 21`: 21 ≥ 10 → n становится 2, count = 2;
2 < 10 → стоп. Ответ: 2 цифры.

### 5.5. `print_score_line` — строка счёта над полем

```c
void print_score_line(int score_left, int score_right) {
    int right_col = 80 - 8 - count_digits(score_right) + 1;
    move_cursor(1, 1);
    printf("\033[1;36mPlayer: %d", score_left);
    move_cursor(1, right_col);
    printf("Player: %d\033[0m", score_right);
}
```

- Текст `Player: ` занимает 8 символов (7 букв + пробел), плюс цифры счёта.
- `right_col` — колонка, с которой надо начать печатать правый счёт, чтобы
  он закончился ровно в колонке 80: от ширины строки отнимаем длину текста
  (8) и длину числа, и добавляем 1, потому что нумерация колонок с 1.
- `\033[1;36m` включает ярко-голубой цвет, `\033[0m` в конце его сбрасывает.

### 5.6. `draw` — отрисовка всего кадра

```c
void draw(int left_paddle, int right_paddle, int ball_x, int ball_y,
          int score_left, int score_right, int winner) {
    int x;
    int y;
    clear_screen();
    print_score_line(score_left, score_right);
    for (y = 0; y < 25; y++) {
        for (x = 0; x < 80; x++) {
            move_cursor(y + 2, x + 1);
            if (x == ball_x && y == ball_y) {
                printf("\033[1;31m*\033[0m");
            } else if (x == 1 && y >= left_paddle - 1 && y <= left_paddle + 1) {
                printf("\033[1;32m#\033[0m");
            } else if (x == 78 && y >= right_paddle - 1 && y <= right_paddle + 1) {
                printf("\033[1;32m#\033[0m");
            } else if (y == 0 || y == 24) {
                printf("\033[37m-\033[0m");
            } else if (x == 0 || x == 79) {
                printf("\033[37m|\033[0m");
            } else if (x == 40) {
                printf("\033[34m:\033[0m");
            } else {
                printf(" ");
            }
        }
    }
    move_cursor(27, 1);
    if (winner == 1) {
        printf("\033[1;35mPlayer 1 (left) wins!\033[0m");
    } else if (winner == 2) {
        printf("\033[1;35mPlayer 2 (right) wins!\033[0m");
    } else {
        printf("\033[33mA/Z: left up/down | K/M: right up/down | Enter: skip turn\033[0m");
    }
    printf("\n");
}
```

Логика:

1. Очищаем экран, печатаем строку счёта (она занимает строку терминала 1).
2. Вложенные циклы перебирают все 25 × 80 клеток. Для каждой клетки:
   - `move_cursor(y + 2, x + 1)` — переводим игровые координаты в экранные.
     `+ 2` к строке, потому что строка 1 занята счётом, а нумерация с 1
     (игровой `y = 0` — это экранная строка 2); `+ 1` к колонке, потому что
     нумерация с 1.
   - Дальше цепочка `if / else if` решает, **что** в этой клетке. Порядок
     проверок важен: проверяем от самого «важного» к менее важному.
     - Совпала с координатами мяча → красная `*`.
     - Колонка 1 и `y` в пределах `left_paddle ± 1` → зелёная `#` (левая
       ракетка).
     - Колонка 78 и `y` в пределах `right_paddle ± 1` → правая ракетка.
     - Первая или последняя строка поля → белая `-`.
     - Первая или последняя колонка → белая `|`.
     - Колонка 40 → синяя `:` центральной линии.
     - Иначе → обычный пробел (пустая клетка).
3. После поля курсор встаёт в строку 27 (25 строк поля + строка счёта = 26,
   значит первая свободная — 27) и печатается нижняя строка: если есть
   победитель — сообщение о победе пурпурным, иначе жёлтая подсказка по
   управлению.

### 5.7. `read_command` — чтение команды игрока

```c
int read_command(void) {
    int c = getchar();
    int d;
    if (c == EOF || c == '\n') {
        return 0;
    }
    d = c;
    while (d != '\n' && d != EOF) {
        d = getchar();
    }
    if (c == 'a' || c == 'A') {
        return 1;
    }
    if (c == 'z' || c == 'Z') {
        return 2;
    }
    if (c == 'k' || c == 'K') {
        return 3;
    }
    if (c == 'm' || c == 'M') {
        return 4;
    }
    return 0;
}
```

По шагам:

1. `c = getchar()` — читаем первый символ из буфера. Если буфер пуст,
   программа ждёт ввода. Это и есть пошаговость: игра стоит, пока игрок не
   нажмёт клавишу и Enter.
2. Если сразу пришёл `'\n'` — игрок нажал Enter без буквы: пропуск хода,
   возвращаем 0. `EOF` — ввод закрыт, тоже считаем пропуском, чтобы не
   зациклиться.
3. Если пришла буква, в буфере после неё остался `'\n'` (от нажатого Enter)
   и, возможно, ещё что-то, если ввели несколько букв. Цикл
   `while (d != '\n' && d != EOF)` вычитывает и выбрасывает всё до конца
   строки, чтобы «мусор» не прочитался как команда на следующем ходу.
4. Дальше буква переводится в код команды: 1 — левая вверх, 2 — левая вниз,
   3 — правая вверх, 4 — правая вниз. Проверяются обе версии — строчная и
   заглавная (`'a' || 'A'`), чтобы не зависеть от Caps Lock.
5. Любая другая клавиша → 0 (пропуск хода).

### 5.8. `apply_command` — применение команды к ракеткам

```c
void apply_command(int command, int *left_paddle, int *right_paddle) {
    if (command == 1) {
        *left_paddle = move_paddle(*left_paddle, -1);
    } else if (command == 2) {
        *left_paddle = move_paddle(*left_paddle, 1);
    } else if (command == 3) {
        *right_paddle = move_paddle(*right_paddle, -1);
    } else if (command == 4) {
        *right_paddle = move_paddle(*right_paddle, 1);
    }
}
```

Функция получает код команды и **адреса** переменных ракеток (иначе она не
смогла бы их изменить). Строка

```c
*left_paddle = move_paddle(*left_paddle, -1);
```

читается так: «взять текущее значение левой ракетки (`*left_paddle`),
передать его в `move_paddle` с направлением `-1` (вверх), а результат
записать обратно по тому же адресу». Команда 0 сюда просто не попадает ни в
одну ветку — ракетки не двигаются.

### 5.9. `move_paddle` — движение ракетки с ограничением

```c
int move_paddle(int paddle_y, int direction) {
    paddle_y += direction;
    if (paddle_y < 2) {
        paddle_y = 2;
    }
    if (paddle_y > 22) {
        paddle_y = 22;
    }
    return paddle_y;
}
```

Сдвигает центр ракетки на `direction` (`-1` вверх, `1` вниз) и не даёт ей
выйти за поле. Границы 2 и 22 взяты не случайно: ракетка занимает три клетки
(центр ± 1), а внутренность поля — строки 1..23. Если центр в строке 2,
верх ракетки в строке 1 — вплотную к границе. Если 22 — низ в строке 23.

### 5.10. `update_seed` — «случайность» без библиотек

```c
void update_seed(unsigned int *seed) {
    *seed = *seed * 1103515245u + 12345u;
}
```

Обычно случайные числа берут из `rand()`, но он живёт в `stdlib.h`, которую
нельзя подключать. Поэтому используется **линейный конгруэнтный генератор** —
формула `next = seed * 1103515245 + 12345`. Это тот же рецепт, что и внутри
настоящего `rand()` во многих библиотеках. Каждое обновление превращает зерно
в новое, внешне непредсказуемое число.

Буква `u` после чисел (`1103515245u`) означает: «это константа типа
unsigned». Зерно — `unsigned int`, и при переполнении (когда произведение не
влезает в тип) значение просто «заворачивается» по модулю 2³² — для
unsigned-типов это гарантировано стандартом и как раз работает на
случайность.

### 5.11. `serve_ball` — подача мяча из центра

```c
void serve_ball(int *ball_x, int *ball_y, int *dir_x, int *dir_y,
                unsigned int *seed) {
    update_seed(seed);
    *ball_x = 40;
    *ball_y = 12;
    if (*seed % 2 == 0) {
        *dir_x = 1;
    } else {
        *dir_x = -1;
    }
    *dir_y = (int)((*seed / 2) % 3) - 1;
}
```

Вызывается в начале игры и после каждого гола. Всё через указатели, потому
что заполнить нужно четыре переменные `main` плюс обновить зерно.

1. `update_seed(seed)` — новое случайное зерно.
2. Мяч ставится в центр: колонка 40, строка 12.
3. Направление по горизонтали: если зерно чётное (`% 2 == 0`) — вправо,
   иначе влево.
4. Направление по вертикали: `(*seed / 2) % 3` даёт 0, 1 или 2; вычитание 1
   превращает это в `-1`, `0` или `1` — вверх, прямо или вниз. Деление на 2
   перед взятием остатка нужно, чтобы выбор `dir_y` не был жёстко связан с
   чётностью, уже использованной для `dir_x`.

### 5.12. `update_ball` — физика мяча

```c
void update_ball(int *ball_x, int *ball_y, int *dir_x, int *dir_y,
                 int left_paddle, int right_paddle,
                 int *score_left, int *score_right, unsigned int *seed) {
    int next_x = *ball_x + *dir_x;
    int next_y = *ball_y + *dir_y;

    if (next_y < 1 || next_y > 23) {
        *dir_y = -*dir_y;
        next_y = *ball_y + *dir_y;
    }
    if (next_x == 1 && next_y >= left_paddle - 1 && next_y <= left_paddle + 1) {
        *dir_x = -*dir_x;
        next_x = *ball_x + *dir_x;
    }
    if (next_x == 78 && next_y >= right_paddle - 1 && next_y <= right_paddle + 1) {
        *dir_x = -*dir_x;
        next_x = *ball_x + *dir_x;
    }
    if (next_x <= 0) {
        *score_right += 1;
        serve_ball(ball_x, ball_y, dir_x, dir_y, seed);
        return;
    }
    if (next_x >= 79) {
        *score_left += 1;
        serve_ball(ball_x, ball_y, dir_x, dir_y, seed);
        return;
    }
    *ball_x = next_x;
    *ball_y = next_y;
}
```

Это самая длинная функция, но идея простая: сначала **предсказать**, куда
мяч попадёт на следующем шаге, проверить столкновения и только потом
подтвердить движение.

1. `next_x`, `next_y` — клетка, в которую мяч собирается шагнуть.
2. **Отскок от пола и потолка.** Внутренность поля — строки 1..23. Если
   следующая строка за пределами, вертикальное направление переворачивается
   (`*dir_y = -*dir_y`) и шаг пересчитывается уже с новым направлением —
   мяч отскакивает.
3. **Отскок от ракеток.** Если мяч шагнул в колонку левой ракетки
   (`next_x == 1`) и при этом попал в диапазон её клеток
   (`left_paddle - 1 .. left_paddle + 1`), горизонтальное направление
   переворачивается, и шаг пересчитывается — мяч летит обратно. То же
   зеркально для правой ракетки в колонке 78.
4. **Гол.** Если мяч дошёл до левой границы (`next_x <= 0`) — правая
   ракетка его пропустила: очко правому игроку (`*score_right += 1`),
   новая подача, и функция завершается досрочно через `return` — координаты
   уже выставила `serve_ball`. Зеркально для правой границы
   (`next_x >= 79`): очко левому.
5. Если ничего не случилось — просто подтверждаем шаг: записываем новые
   координаты в переменные `main`.

Порядок проверок важен: отскок от ракетки проверяется **до** гола. Если мяч
шагнул в колонку 1, где стоит ракетка, он отскочит и до гола дело не дойдёт.

Заметьте: `left_paddle` и `right_paddle` переданы по значению (физика мяча
не меняет ракетки — ей нужно только знать, где они), а всё, что функция
меняет, — по указателю.

## 6. Один ход глазами программы

Соберём всё воедино. Игрок нажимает `a` и Enter:

1. `main` вызывает `draw` — поле рисуется по текущим числам.
2. `read_command` читает `'a'` из буфера, выбрасывает оставшийся `'\n'`,
   возвращает `1`.
3. `apply_command` видит код 1 и делает
   `*left_paddle = move_paddle(*left_paddle, -1)` — левая ракетка поднялась
   на клетку (если не упёрлась в край).
4. `update_ball` предсказывает шаг мяча, при необходимости отражает его от
   стен/ракеток или фиксирует гол и подаёт заново.
5. `main` проверяет счёт: если кто-то достиг 21 — `winner` меняется, цикл
   заканчивается, и финальный `draw` показывает сообщение о победе.
6. Иначе цикл повторяется: новый кадр, новая команда.

## 7. Компиляция и запуск

```sh
gcc -Wall -Wextra -Werror pong.c -o pong
./pong
```

- `gcc` — компилятор; `pong.c` — исходник; `-o pong` — имя готовой программы.
- `-Wall -Wextra` — включить предупреждения о подозрительных местах в коде.
- `-Werror` — считать предупреждения ошибками: с ними программа просто не
  соберётся. Хорошая привычка.

Для игры нужен терминал, понимающий ANSI-последовательности (macOS Terminal,
iTerm2, почти все терминалы Linux). Окно терминала должно быть не уже
80 колонок и не ниже 27 строк, иначе кадр «поедет».

|-------------------|------|
